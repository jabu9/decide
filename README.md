# 🎡 Decide

**Can't decide? Let the wheel choose.**

A tiny, dependency-free spin-the-wheel decision maker. Type your options, hit spin, and get an answer.

**▶ Try it:** https://jabu9.github.io/decide/

## Features

- **One file.** Plain HTML, CSS, and JavaScript. No build step, no frameworks.
- **Shareable links.** "Copy link" puts your options in the URL so friends can spin the same wheel.
- **Elimination mode.** Each winner is removed from the wheel, which is handy for ranking things or picking a draft order.
- **Remembers your list.** Your options are saved in your browser's local storage.
- **Juicy feedback.** Tick sounds made on the fly with the Web Audio API, plus confetti (off if you've turned on reduced motion).
- **Keyboard friendly.** Press `Space` to spin and `Esc` to close the result.
- **Light and dark themes** that follow your system setting.
- **Private.** No analytics, no cookies, no servers.

## Run locally

Just open `index.html` in a browser. That's it.

## Share a wheel

Links have the form `.../#Option A|Option B|Option C`. For example:

https://jabu9.github.io/decide/#Pizza|Sushi|Tacos
